# Diagram Version Log

Tracking revisions to the RMF lifecycle diagram used in this repository's README and associated publications.

## v1.0 (2026-08-26)

Initial published version. Seven-step NIST SP 800-37 Rev. 2 lifecycle (Prepare, Categorize, Select, Implement, Assess, Authorize, Monitor), rendered in BridgeCore AI's navy and teal brand palette, with the RMF-is-iterative and Benefits callouts, referenced against NIST SP 800-37 Rev. 2.

File: `rmf-lifecycle-diagram-v1.0.png`

## Versioning convention

Each new version gets its own file, named `rmf-lifecycle-diagram-vX.X.png`, never overwriting a prior version's file. This keeps every version that has ever been published or linked externally (Substack, LinkedIn, the website) permanently resolvable, even after a newer version replaces it as the current default in the README.

Bump the minor version (v1.1, v1.2) for visual or wording corrections that don't change the underlying lifecycle content. Bump the major version (v2.0) if the diagram's structure or content changes meaningfully, for example, if a step's description is revised or a new reference standard is cited.
